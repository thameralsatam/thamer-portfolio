# Thamer Alsatam - Portfolio

A React + TypeScript application rewritten from the original portfolio site, built with Vite.

## Features

- **About & Navigation**: Smooth navigation between sections (Über mich, Anmelden, Kontakt).
- **Skill Overview**: Displays known technologies (HTML) and currently learned skills (CSS, JavaScript).
- **Interactive Login**: Interactive test login form with state handling, error validation, and confirmation state.
- **Accordion Info**: Expandable details about Thamer Alsatam.
- **Contact Details**: Direct links for email and phone number.
- **Authentic Theme**: Retains the original dark teal (`#054239`) and gold (`#b9a779`) aesthetic.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
